# 🌱 Bakawala

**A Physics-Informed Ensemble Framework for Mangrove Loss Prediction — Philippines**

*bakawan* (mangrove) + *wala* (gone)

## About

Bakawala predicts severe mangrove loss across Philippine coastal barangays 
and prioritizes flood-protection restoration sites using a physics-informed 
ensemble machine learning model.

## Model Performance
- AUC = 0.732 (95% CI: 0.705–0.748)
- Temporal hold-out AUC = 0.708
- Return on Investment: 41.3:1
